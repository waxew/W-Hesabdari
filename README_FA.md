# W-Hesabdari

# سیستم حسابداری جامع کسب و کارها

## معرفی پروژه

W-Hesabdari یک پروژه نرم افزاری برای ساخت یک هسته حسابداری جامع، مستقل و قابل توسعه است.

هدف پروژه ساخت یک موتور حسابداری مرکزی است که وابسته به نوع کسب و کار، نام برند یا ظاهر برنامه نباشد.

این هسته می‌تواند برای کسب و کارهای مختلف نسخه‌های مستقل تولید کند.

نمونه نسخه‌ها:

- حسابداری فروشگاه ۱
- حسابداری سالن فشیال ۳
- حسابداری موبایل فروشی ۲
- حسابداری شرکت خدماتی

بدون تغییر در منطق اصلی برنامه، فقط با تغییر پروفایل کسب و کار، نسخه جدید ساخته می‌شود.

---

# هدف معماری پروژه

در این پروژه دو بخش کاملاً جدا وجود دارد:

## 1- Accounting Core

هسته اصلی حسابداری که شامل منطق ثابت نرم افزار است:

- سیستم حساب‌ها
- کدینگ حسابداری
- اسناد مالی
- بدهکار و بستانکار
- دفتر کل
- گزارش‌های مالی
- فاکتور
- دریافت و پرداخت
- انبار
- محاسبات مالی

این بخش نباید هیچ وابستگی به یک کسب و کار خاص داشته باشد.

---

## 2- Business Profile

تمام اطلاعات اختصاصی هر کسب و کار در این بخش قرار می‌گیرد.

شامل:

- شناسه کسب و کار
- نام برنامه
- نام برند
- Package Name
- لوگو
- آیکون برنامه
- رنگ سازمانی
- تصاویر
- متن‌های برنامه
- امکانات فعال
- تنظیمات اختصاصی

مثال:

```text
Business ID:
store_001

Business Name:
فروشگاه ۱
```

یا:

```text
Business ID:
facial_003

Business Name:
سالن فشیال ۳
```

# قوانین مهم پروژه

1. هسته حسابداری همیشه مستقل باقی می‌ماند.

2. اطلاعات کسب و کار فقط داخل Business Profile قرار می‌گیرد.

3. برای ساخت نسخه جدید، Core تغییر نمی‌کند.

4. هر قابلیت جدید باید همراه با مستندات فارسی اضافه شود.

5. نسخه‌های مختلف کسب و کار از یک هسته مشترک ساخته می‌شوند.
