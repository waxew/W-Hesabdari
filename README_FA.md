# W-Hesabdari

## معرفی پروژه

این پروژه یک هسته نرم افزاری حسابداری جامع برای کسب و کارها است.

هدف اصلی:

ساخت یک موتور حسابداری مستقل از نوع کسب و کار که بتوان با تغییر یک فایل تنظیمات، نسخه های مختلف نرم افزار را برای کسب و کارهای مختلف تولید کرد.

## معماری کسب و کار محور

اطلاعات اختصاصی هر کسب و کار در بخش جداگانه نگهداری می شود.

نمونه:

- فروشگاه ۱
- سالن فشیال ۳
- موبایل فروشی ۲

بدون تغییر در هسته برنامه فقط با تغییر پروفایل کسب و کار می توان نسخه جدید ایجاد کرد.

## قوانین توسعه

- تمام سورس ها دارای توضیحات فارسی هستند.
- امکانات به صورت سلسله مراتبی اضافه می شوند.
- هسته حسابداری نباید وابسته به نام یا برند کسب و کار باشد.
