# Business Profile System

## هدف

ساخت هسته حسابداری مستقل از نوع کسب و کار.

Core حسابداری نباید شامل اطلاعات اختصاصی فروشگاه، شرکت، رستوران یا کلینیک باشد.

## معماری

Accounting Core Engine
+
Business Profile
+
Accounting Modules
+
Financial Configuration Engine

## Business Profile مسئول نگهداری موارد زیر است:

- اطلاعات هویتی
- برندینگ
- تنظیمات ظاهری
- تنظیمات مالی
- ماژول های فعال

## نمونه نسخه ها

Retail Accounting

Manufacturing Accounting

Service Company Accounting

Restaurant Accounting

Distribution Accounting

## قانون توسعه

هر قابلیت عمومی در Core قرار می گیرد.

هر قابلیت اختصاصی کسب و کار در Module یا Profile قرار می گیرد.
