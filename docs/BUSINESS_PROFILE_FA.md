# Business Profile Architecture

## هدف

این بخش مسئول نگهداری تمام اطلاعاتی است که به یک کسب و کار خاص مربوط می‌شود.

هسته حسابداری نباید هیچ اطلاعاتی از برند، نام فروشگاه یا نوع کسب و کار داشته باشد.

## اطلاعات قابل تنظیم

- شناسه کسب و کار
- نام کسب و کار
- نام برنامه
- Package Name
- لوگو
- آیکون
- رنگ سازمانی
- متن‌های برنامه
- تصاویر
- امکانات فعال

## مثال

فروشگاه ۱:

```
businessId = store_001
businessName = فروشگاه ۱
```

سالن فشیال ۳:

```
businessId = facial_003
businessName = سالن فشیال ۳
```

## قانون مهم

تغییر Business Profile نباید باعث تغییر در Accounting Core شود.

Core همیشه مستقل باقی می‌ماند.
