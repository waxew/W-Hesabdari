# معماری W-Hesabdari

## اصل اصلی

هسته حسابداری مستقل است و نباید اطلاعات یک کسب و کار داخل آن قرار بگیرد.

## Business Profile

تمام اطلاعات متغیر در یک لایه جدا قرار می گیرد:

- نام کسب و کار
- شناسه برنامه
- package name
- آیکون
- لوگو
- رنگ سازمانی
- متن ها
- تصاویر
- تنظیمات فعال بودن امکانات

## جریان تغییر نسخه

↓

Build

یا:
