# سلسله مراتب ماژول های W-Hesabdari

## Core Layer

هسته مستقل نرم افزار:

1. Accounting Engine
2. Party Management
3. Invoice Engine
4. Cash & Bank Engine
5. Inventory Engine
6. Reporting Engine

## Business Layer

امکاناتی که بر اساس نوع کسب و کار فعال می شوند.

نمونه:

- فروشگاه
- سالن زیبایی
- موبایل فروشی

## Application Layer

مسئول نمایش و تعامل کاربر:

- صفحه ها
- منوها
- تنظیمات ظاهری
- برندینگ

## قانون توسعه

هر امکان جدید ابتدا باید مشخص شود:

1. مربوط به Core است یا Business
2. چه ارتباطی با حسابداری دارد
3. چه جداولی نیاز دارد
4. چه مستنداتی باید اضافه شود
