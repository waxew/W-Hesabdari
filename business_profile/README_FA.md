# Business Profile System

## معرفی

Business Profile لایه تنظیمات کسب و کار است و از Accounting Core جدا می باشد.

هسته حسابداری نباید وابسته به نام، برند یا نوع کسب و کار باشد.

## ساخت نسخه جدید

برای ساخت نسخه جدید فقط یک Profile جدید ایجاد می شود.

## ساختار Profile

هر Profile مشخص می کند:

- نوع کسب و کار
- Module های فعال
- Attribute Schema های فعال
- تنظیمات مالی
- تنظیمات ظاهری

## تفاوت Module و Attribute Schema

Module دارای منطق، فرآیند و Workflow است.

Attribute Schema فقط اطلاعات توصیفی و متغیر است.

## قوانین

موارد اختصاصی کسب و کار نباید وارد Core شوند.
